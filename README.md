# Workout Buddy

A static PWA for choosing a muscle group, browsing 168 workouts, searching and filtering across every muscle group, learning how to do each exercise, watching real in app exercise demos from ExerciseDB, saving exercises into a quick plan, and opening saved workouts in a full screen coaching view.

## Run locally

```bash
python -m http.server 5173
```

Open `http://localhost:5173`.

## Put it on GitHub

1. Create a new GitHub repository.
2. Upload these files or push them with Git.
3. Keep `index.html` at the repository root.

## Deploy on Netlify

1. In Netlify, choose **Add new site**.
2. Connect the GitHub repository.
3. Build command: leave empty.
4. Publish directory: `.`.
5. Deploy.

## Add to iPhone Home Screen

1. Open the Netlify site in Safari.
2. Tap Share.
3. Tap **Add to Home Screen**.
